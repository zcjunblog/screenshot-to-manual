# 截图转操作手册 Implementation Plan

> **For agentic workers:** 按用户已批准的design.md连续实施；本会话直接实现，完成后做独立审查。

**Goal:** 交付可导入的跨客户端Skill，把真实输入截图和说明整理成可追溯的图文手册。
**Architecture:** Agent负责图像理解与步骤判断；Python负责不可变来源索引、结构校验、确定性标注/脱敏和独立目录导出。通用源码构建标准与WorkBuddy双包。
**Tech Stack:** Python3.9+，Pillow必需；python-docx和LibreOffice可选，用于Word/PDF。包不含开发机运行时、字体或绝对路径。
**Spec:** memory-bank/design.md

## Global Constraints
- 保留原图，不伪造操作证据；开发演示截图来自实际运行的本地虚构演示程序，明确标明用途。
- 缺图、推断、顺序未知和业务结果不能伪装成已验证步骤；默认草稿。
- 原坐标绑定EXIF归正后的尺寸；先像素脱敏，再裁切/标注，只内嵌处理副本。
- 仅处理输入文件；不自动访问账号、点击目标软件或发布手册。
- 对外资产相对路径，导出ZIP不夹带内部来源与原图；重复运行不覆盖。

## Review Focus
- 输入修改、重复文件、EXIF方向与超大图片：建立hash和尺寸，渲染前核对。
- 非法坐标、裁切漂移、标注遮挡：检查原图边界、先脱敏再变换，标签放图外上方。
- 来源造假与不确定动作：说明引文精确匹配；图像语义由Agent/人工复核。
- 脱敏泄漏：检查PNG像素、DOCX内嵌资源和移交ZIP，输出不复制原图。
- 无Word/PDF依赖与转换失败：明确降级，不能宣称不存在的文件成功。

## Tasks
1. 来源与步骤协议：scripts/intake.py、validate.py、common.py，references/schema.md、templates/manual.json。先写失败测试，再实现manifest/说明引文/校验及安全边界。
2. 图像与文档交付：scripts/images.py、export.py、manual_tool.py；先测像素遮盖、裁切坐标、相对路径、防覆盖、内容一致，再实现Markdown、DOCX、PDF及移交ZIP。
3. Skill与分发：SKILL.md、运行说明、Codex元数据、双包工具；校验双语示例数量、资源完整及解压独立运行。
4. 真实演示验证：实际运行演示页面并截图，制作桌面、移动和混合流程样例；测试乱序/缺失/重复/模糊/脱敏。渲染检查每页Word/PDF，独立使用和代码审查，尽可能完成WorkBuddy实测。
5. 交付：README、CHANGELOG、design/todo、evidence；保留未完成验证，提交推送GitHub，核对摘要和远程提交。
